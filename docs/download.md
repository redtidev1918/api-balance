# 下载 api-balance

**语言 / Language:** 中文 · [English](/en/download.md)

本页汇总最新安装包与获取方式。完整资产与历史版本见 [Releases](https://github.com/redtidev1918/api-balance/releases)。

## 发布产物

| 平台 | 包 | 说明 |
| :-- | :-- | :-- |
| Windows | `api-balance-<version>-windows-x64.zip` | 解压即用 |
| macOS | `api-balance-<version>-macos-arm64.tar.gz` | 首次运行需在「隐私与安全性」中放行 |
| Linux | `api-balance-<version>-linux-x64.tar.gz` | 解压后 `chmod +x` |

校验文件：`SHA256SUMS`。

## 校验下载

```bash
sha256sum -c SHA256SUMS
```

## 其他获取方式

- npm：`npm install api-balance`
- 源码：`git clone https://github.com/redtidev1918/api-balance.git`
